Only GeoJSON Point features are supported. Polygon, LineString and other geometry types will be skipped. Each feature's properties must include id, category, status, created_at, and text.
PDF ingestion — Only tabular complaint tables in structured PDFs are supported. Scanned images in PDFs require OCR, which is not performed by this browser interface.
OCR prerequisites (CLI only): PDF text extraction via OCR requires python-poppler or pdf2image, pytesseract, and a working Tesseract installation. Run omnigrid ingest --help for details. OCR is not available in this browser preview — extracted text comes from the PDF's embedded text layer only.
